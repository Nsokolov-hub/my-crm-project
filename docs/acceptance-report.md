# Состояние приёмки базовой CRM

**Дата проверки:** 24 сентября 2026 г.

**Версия проверки:** ветка `codex/business-friendly-settings` с комплектом передачи

**Статус:** готова к ручной приёмке владельцем на тестовых данных. Решение о вводе с реальными данными принимает владелец после проверки сценария и утверждения настроек расчёта.

Предыдущая версия этого документа заявляла «100% принято». Эта оценка не подтверждалась фактической работой CI и не учитывала ошибки в оплатах, поставках и правах доступа. Ниже приведены результаты повторной проверки.

## Исправлено для повседневной работы

- Оплата и обратное распределение пересчитывают финансирование принятого состава. Уведомление об обратной операции получает владелец каждой затронутой заявки.
- Исполнение можно исправить без разрушения истории: пересмотреть невыставленное количество, отменить неоплаченную позицию после аннулирования счёта, выбрать другого поставщика и выпустить новые документы. Оплаченный или распределённый в поставку состав защищён от случайной отмены.
- Состояния волн поставки остаются в допустимом наборе. Общая волна оценивается по всем её заявкам; закрытая волна не открывается сама при пересчёте.
- Ответы API учитывают текущие финансовые права, в том числе при повторе команды с тем же ключом. Скачивание вложений проверяет право доступа к исходной заявке.
- Причина закрытия заявки, справочники результатов звонков и срок задачи корректно передаются интерфейсом. Для новых администраторов добавлены права настройки этих справочников.
- CI запускает базовые тесты без подключения к посторонней базе; браузерные Playwright-сценарии больше не попадают в Vitest.

Дальнейшие ручные шаги и поля ожидаемого результата находятся в [чек-листе](manual-acceptance-small-team.md). Комплект для другой команды описан в [инструкции передачи](handover-deployment.md).

## Граница готовности

CRM предназначена для небольшой команды и умеренного объёма. Старые данные компании, экстремальная нагрузка и развёртывание в публичном интернете не являются частью этой приёмки. Формулы, налоги, курсы, реквизиты, шаблоны и права доступа оставлены настраиваемыми по решению владельца. До их проверки используйте только тестовые заявки и не выпускайте реальные финансовые документы.

Копия и восстановление проверены только на синтетической тестовой установке. Перед использованием реальных данных повторите восстановление в выделенной среде с вашей конфигурацией и правилами хранения копий.
