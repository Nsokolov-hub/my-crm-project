# Импортный расчёт: финальные формулы от 5 октября 2026

Формулы соответствуют текстовому ТЗ «Поставка А» с уточнением от 5 октября: база наценки — таможенная стоимость плюс пошлина; вывоз из аэропорта относится ко всей волне, СДЭК и доставка в Москве — к конкретному расчёту. Рентабельность здесь означает долю валовой прибыли в продаже без НДС. Отношение прибыли к себестоимости называется «Доходность затрат».

## Формулы строки товара

Суммы относятся ко всей строке квоты. Для строки из одной единицы это суммы на одну единицу. Q — число единиц в строке, Qw — число единиц во всей волне, Qr — число единиц в текущем расчёте, K — коэффициент наценки, v — ставка НДС как доля (22% = 0,22).

| Показатель | Формула |
|---|---|
| Закупка в рублях P | Цена единицы в валюте × Q × курс |
| Международная логистика L | Общая логистика волны в рублях × Q / Qw |
| Таможенная стоимость | P + L |
| Пошлина D | Таможенная стоимость × ставка группы |
| База ввозного НДС / ННБ | P + L + D |
| Ввозной НДС V | ННБ × v |
| Таможенная стоимость с пошлиной и ввозным НДС | ННБ + V |
| Чистая стоимость C при вычете НДС | ННБ |
| Чистая стоимость при выключенном вычете | ННБ + V |
| База наценки M | Таможенная стоимость + пошлина = ННБ, при любом режиме вычета |
| Цена с наценкой | M × K, до добавления перевыставляемых расходов |
| Логистика РФ — вывоз из аэропорта | Общий вывоз волны × Q / Qw |
| Доставка клиенту — СДЭК и Москва | (СДЭК текущего расчёта + доставка в Москве текущего расчёта) × Q / Qr |
| Логистика внутри РФ всего | Доля вывоза из аэропорта + доля СДЭК + доля доставки в Москве |
| Прочие расходы E | Доли брокера, логистики РФ, терминала, валютного контроля и комиссии за перевод |
| Доля обычного общего расхода | Общая сумма статьи × Q / Qw при методе «По количеству» и области «Волна» |
| Таможенный сбор T | Доля сбора по шкале для обычных товаров либо доля отдельного сбора колонок |
| Себестоимость до финансирования S0 | C + E + T |
| Финансируемая сумма | S0 × доля отсрочки / 100 |
| Стоимость финансирования F | Финансируемая сумма × годовая ставка × дни отсрочки / база дней |
| Цена до бонусов без НДС N0 | M × K + E + T + F + V только при выключенном вычете |
| Прибавка от наценки, ₽ | M × (K − 1) для импорта |
| Бонус B | N0 × (коэффициент бонуса − 1) + дополнительные настроенные бонусы |
| Сервисная комиссия J | Комиссия за вывод бонуса + дополнительная комиссия |
| Себестоимость S | S0 + F + B + J |
| Продажа без НДС N | N0 + B + J |
| НДС продажи | N × v |
| Продажа с НДС | N + НДС продажи |
| Валовая прибыль G | N − S |
| Рентабельность | G / N × 100% |
| Доходность затрат | G / S × 100% |
| НДС к уплате при вычете | Максимум(0; НДС продажи − V) |
| Денежные затраты на заказ | P + статьи денежных расходов + D + T + V + F + B + J |

Международная логистика и пошлина входят в базу наценки. E, T и F добавляются после наценки. Вывоз из аэропорта и доставка клиенту являются частями E: показатель «Логистика внутри РФ всего» справочный и повторно не прибавляется. Ввозной НДС не входит в базу наценки: при вычете оплачивается при ввозе и учитывается в денежных затратах; без вычета добавляется к себестоимости и цене после наценки. Предоплата клиента не вычитается из «Денежных затрат на заказ». При доле отсрочки 0% финансируемая сумма и проценты равны нулю.

В интерфейсе отдельно показываются «Цена с наценкой» и «Валовая прибыль». Для базы 15 792 ₽ и коэффициента 1,5 цена с наценкой равна 23 688 ₽, прибавка и валовая прибыль без дополнительных корректировок — 7 896 ₽. Валовая прибыль считается как продажа без НДС минус себестоимость: перевыставляемые расходы увеличивают обе суммы одинаково.

Например, в волне 12 единиц, в расчёте клиента — 2. Вывоз из аэропорта стоит 1 200 ₽, СДЭК этому клиенту — 400 ₽, доставка по Москве — 600 ₽. Доля вывоза в расчёте равна 200 ₽, клиентская доставка — 1 000 ₽, вся внутренняя логистика расчёта — 1 200 ₽, или 600 ₽ на единицу. Оставшиеся 1 000 ₽ вывоза относятся к другим позициям волны; СДЭК и Москва этого клиента к ним не относятся.

Категории «Вывоз из аэропорта — вся волна» и «Доставка клиенту — этот расчёт» закрепляют область и распределение по количеству. Старые статьи «Логистика РФ», «Доставка клиенту в Москве» и автоматически созданный СДЭК распознаются при новом расчёте. Если статья названа иначе, выберите соответствующую категорию. Бюджет вывоза наследуется между расчётами одной волны, доставка другого клиента не наследуется.

Ставки групп сохраняются: обычные настроенные группы — 5%, штаммы — 12%, колонки — 0% пошлины. Сбор колонок — 73 800 ₽ один раз на волну, распределяется только между колонками по количеству. Шкала остальных товаров применяется к их таможенной стоимости без колонок.

Проверка расходов из Excel: брокер 22 000 ₽, логистика РФ 14 962,50 ₽, терминал 2 000 ₽. В формулах «Стандарты»!T2 и U2 общая сумма валютного контроля равна 10 × 79 × 1,22 = 963,80 ₽, перевода — 40 × 79 = 3 160 ₽. В самой таблице эти комиссии делятся на 34; в тесте общие суммы распределяются по текущей волне из 12 единиц согласно текстовому ТЗ. Доли товара 1 — 80,32 ₽ и 263,33 ₽. На рабочем заказе вводятся реальные уплаченные общие суммы.

Чтобы проверить сбор 2 462 ₽, тест содержит ещё 11 обычных единиц по условной цене 17 000 INR: полный таможенный состав волны попадает в диапазон 200 000,01–450 000 ₽. Эта цена — условие теста; фактические цены остальных товаров пользователь не сообщал. Выбор диапазона в рабочей системе производится по реальному составу волны.

После распределения с сохранением общей суммы статей доля E + T товара 1 равна 3 795,69 ₽. Продажа без НДС — 27 483,69 ₽; с НДС — 33 530,10 ₽; валовая прибыль — 7 896,00 ₽; рентабельность — 28,73%. Итог отличается от Excel из-за распределения комиссий на 12 вместо 34. Кроме того, из-за распределения копеек доли могут на копейку отличаться от округления каждой дроби Excel отдельно. Сумма всех долей всегда совпадает с общим расходом.

## Совместимость и установка

Изменение не требует миграции БД. Сохранённые расчёты и выпущенные документы не переписываются. Для исторических результатов интерфейс берёт рентабельность от продажи из сохранённого `margin_percent`, а прежний `profitability_percent` показывает как доходность затрат. Новые расчёты сохраняют оба явно различающихся показателя; `margin_percent` оставлен для совместимости API.

В расчётах, фактических итогах волн и отчёте по менеджерам одинаковое определение: валовая прибыль / продажа без НДС. Общий процент рассчитывается от суммарных прибыли и продажи, не как среднее процентов строк.

В новых профилях по умолчанию выключено округление цены единицы вверх до целого рубля: счёт считается до копеек. Для существующего профиля настройка сохраняется. Если требуется расчёт до копеек как в приложенной таблице, создайте новую редакцию профиля, выключите «Округлять цену за штуку с НДС вверх до рубля», проверьте курсы, расходы и вычет НДС, затем опубликуйте. При явно включённом округлении цена товара 1 с НДС будет 33 531,00 ₽, а цена без НДС останется 27 483,69 ₽.

DAP и РФ сохраняют прежние ценовые формулы. В DAP исправлено справочное поле суммы наценки: оно теперь учитывает всю фактическую базу C + E, как сама цена продажи. Наценка DAP и прибыль больше не расходятся из-за исключённого E в справочном поле.
