# Анализ пробелов

Полное ТЗ изучено. П1: F01–F16, XLSX-обмен F18, N01–N08, A01–A22. П2: F17, внешние интеграции F18, фактическая доходность, A23. П3: F19/A24. Исключены УПД, полноценный бухгалтерский/налоговый/складской/кадровый учёт, производство, кабинеты и мобильные приложения, видеозвонки.

В02–В15 не имеют конкретных значений. Решение пользователя: настраиваемая CRM. Реализуются версионируемые настройки и права; реальных реквизитов, ставок, сотрудников и правил не выдумывать. Публикация профилей фиксирует утверждающего пользователя. Неполные настройки дают явную предметную ошибку. В01: доступный репозиторий пуст, исходные данные миграции не предоставлены. N01/N06 требуют фактической проверки; никаких заявлений о production-готовности без A22.
