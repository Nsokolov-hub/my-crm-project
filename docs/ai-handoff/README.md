# Передача разработки другой ИИ

Подготовлено 19.09.2026 по текущему коду проекта и исходному ТЗ. Этот пакет содержит оценку, порядок доработки и правила проверки результата. Код приложения при подготовке плана не исправлялся.

## Порядок чтения

1. `READINESS.md` — оценка готовности и подтверждённые ограничения.
2. `START-PROMPT.md` — текст, который нужно передать следующей ИИ вместе с доступом к репозиторию.
3. `IMPLEMENTATION-PLAN.md` — последовательность этапов, конкретные задачи и критерии завершения.
4. `REVIEW-PROTOCOL.md` — формат отчётов, проверка результата и передача куратору.

Оценка готовности основной поставки П1 — **около 40%**, с ориентировочной погрешностью ±10 процентных пунктов. Это инженерная оценка готовности к сдаче, а не доля написанных строк или пройденных требований.

Основная работа впереди — устранить нарушения бизнес-правил и доступа, довести уже существующие экраны и доказать работу продукта на PostgreSQL, в контейнерах и после восстановления. Начинать заново или менять стек не требуется.

План рассчитан на существующую архитектуру: Python/FastAPI, PostgreSQL/SQLAlchemy/Alembic, React/TypeScript/Vite, фоновые задания и приватные файлы. Следующая ИИ сначала сверяет состояние своей ветки: после загрузки в GitHub коммиты и файлы могут отличаться от проверенного снимка.

Куратор подключается по переданному репозиторию, ветке/PR и отчёту. Само наличие этого пакета не запускает автоматическое наблюдение за GitHub.
