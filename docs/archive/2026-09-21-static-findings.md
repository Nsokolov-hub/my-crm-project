# Дефекты (Defects)

| Статус | Приоритет | Проблема | Где искать | Требуемое доказательство исправления |
|---|---|---|---|---|
| STATIC_FINDING | Критичный | Закупочные финансовые права проверяются через наличие разрешения без области конкретной заявки | `commerce/procurement.py`, `core/security.py` | `requests.read=all` и `finance.purchase.read=own` не раскрывают закупку чужой заявки |
| STATIC_FINDING | Критичный | Повтор команды может вернуть старый полный JSON после отзыва права на закрытые поля | `core/service.py:idem`, `commerce/financial.py` | После отзыва права повтор старого ключа не отдаёт закрытый snapshot и не создаёт вторую операцию |
| STATIC_FINDING | Критичный | Платёж может показать распределения по счетам из других, недоступных заявок | `commerce/payments.py:payment_view` | Доступ к исходной заявке не открывает чужие счета/ссылки/суммы |
| STATIC_FINDING | Критичный | Округление частичных сумм способно дать отрицательный последний остаток | `commerce/documents.py:partial_amount` | Для net=0.02, quantity=4, четырёх частей по 1 нет отрицательных частей; сумма частей точно 0.02 |
| STATIC_FINDING | Высокий | Явный null в PATCH обходит некоторые ограничения; seller_id=null обходит условие проверки смены продавца | `crm/schemas.py`, `crm/routes.py:edit_request` | Обязательные поля не обнуляются; продавец документа защищён и для null |
| STATIC_FINDING | Высокий | Изменение потребности не проверяет уже принятое количество и смену единиц | `crm/routes.py:edit_item` | Нельзя уменьшить потребность ниже принятого объёма или сменить единицу с нарушением пересчёта |
| STATIC_FINDING | Высокий | Нет законченного процесса исправления/отмены принятого состава и нового согласования | `commerce/documents.py`, `commerce/fulfillment.py` | Полный A16: возврат → изменение состава → новое согласование → старое решение неприменимо |
| STATIC_FINDING | Высокий | Профили и финансовые поля не имеют полного раздельного ограничения доступа | `commerce/financial.py`, `communication/access.py` | Каждое финансовое разрешение и его scope проверяются отдельно; параметры вознаграждения не раскрываются через профиль |
| STATIC_FINDING | Высокий | Отчёты и детализация не совпадают по фильтрам и контрактам, задачи доступны разными путями неодинаково | `analytics/routes.py`, `crm/routes.py`, `frontend/src/pages/Dashboard.tsx` | A19 и негативные проверки доступа через dashboard/next_task |
| STATIC_FINDING | Высокий | UI файлов использует неподдерживаемую классификацию, непрочитанные и сроки имеют несовпадения | `pages/Communication.tsx`, `app/Layout.tsx`, формы дат | Реальная загрузка закрытого файла; корректный счётчик; сохранение срока без изменения времени |
| STATIC_FINDING | Высокий | Backup/restore-оболочки ссылаются на отсутствующий обработчик | `scripts/backup.sh`, `scripts/restore.sh` | Полное восстановление БД и файлов в отдельную среду |
