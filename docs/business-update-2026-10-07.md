# Правки бизнеса от 7 октября 2026

В квотах можно открыть позицию и удалить её либо всю квоту поставщика. Удаление убирает квоту из рабочих списков, истории актуальных цен и подстановки последней цены. Исходные строки остаются в базе для истории: ранее сохранённые расчёты, выпущенные КП, счета и их файлы не меняются. Новый расчёт или новое КП из удалённой квоты выпустить нельзя. Доступ к удалению определяется правом `quotes.write` на заявку; повторная отправка команды не дублирует действие. Импорт показывает имя поставщика до записи.

В расчёте поставщик и срок из каждой квоты видны рядом с товаром. При выпуске КП расчёт выбирается по номеру версии, без длинного описания источника. Бонус вводится один раз в строке позиции. Общий ввод бонуса внизу формы убран, отдельная сервисная комиссия сохранена. Для старых API-клиентов общая корректировка остаётся запасным источником бонуса только у позиций с коэффициентом 1. Если у позиции уже указан бонус, повторно общий бонус к ней не добавляется. Старый общий бонус при создании новой версии переносится в коэффициенты строк; неизменяемые расчёты сохраняют прежние суммы.

КП и счета по умолчанию действуют пять календарных дней. Более короткий срок допустим; сервер ограничивает любой более длинный запрос пятью днями с даты выпуска по часовому поясу компании. Прошедшую дату сервер отклоняет. Срок действия документа отделён в печатной форме от договорных условий оплаты.

Новые PDF и XLSX коммерческого предложения содержат:

- Заголовок вида «Коммерческое предложение №14 от 07.10.2026» и даты в формате `ДД.ММ.ГГГГ`.
- Таблицу с зелёной шапкой, чередованием светлых строк и яркой строкой итогов.
- Текст над подписью: «Срок действия предложения 5 календарных дней. Оплата согласно договору. Не является офертой.»
- Подпись: «Генеральный директор ________ /Гильмутдинов Т.Ф».
- Сайт `https://ogk-chem.ru` и почту `info@ogk-chem.ru` внизу.

Номер заявки в печатное КП не выводится. Внутренний уникальный номер документа сохраняется для истории и идентификации. Подпись в счёте продолжает использовать реквизиты продавца.

Письмо поставщику и файл XLSX запроса используют одну функцию построения таблицы. Для импортированных позиций сохраняются исходные названия и порядок столбцов, значения, производитель, Art / CAS и фасовка. При ручном вводе количество выводится без лишних нулей. HTML экранирует названия и значения. Поле «Копия» изначально заполнено `info@ogk-chem.ru`; его можно очистить или указать несколько адресов через запятую. Копия проверяется до постановки письма в очередь, сохраняется в базе и передаётся в SMTP как Cc. Изменение копии требует нового предпросмотра.

## Обновление

Перед запуском новой версии примените миграцию `b5131005` после `b5131004`. Она добавляет признак архивирования квот и список копий письма, заполняет безопасные значения для старых записей и обновляет PostgreSQL-триггеры истории. Существующие суммы и документы не пересчитываются.

В установленном Docker-стенде после получения исходников:

```bash
docker compose build api web
docker compose run --rm migrate
docker compose up -d api worker web
```

Обычный порядок резервного копирования описан в [инструкции эксплуатации](deployment.md).

## Ручная приёмка

1. Загрузить квоты XLSX и проверить поставщика в предпросмотре; открыть позицию и удалить ошибочную строку. Проверить, что остальные строки доступны.
2. Удалить квоту целиком и убедиться, что её цены не подставляются при создании следующей квоты. Проверить сохранность старого КП.
3. Создать расчёт с бонусом `1.15`: бонус должен начислиться один раз, а комиссия за его вывод — по профилю. Внизу формы доступна только сервисная комиссия.
4. Открыть записанный расчёт и проверить поставщика и сроки каждой позиции. При выпуске КП выбрать его по номеру.
5. Выпустить КП и счёт, проверить дату действия через пять дней, подпись, стандартный текст, отсутствие номера заявки и оформление PDF/XLSX.
6. Загрузить таблицу `Name / Produce / Art / CAS / Packing / Qty`; сравнить письмо в предпросмотре с XLSX-запросом. Проверить, что значения `Your`, `70374-39-9`, `250 mg`, `1` сохранились.
7. Указать адреса копии, повторить предпросмотр и отправить тестовое письмо: каждый поставщик получает отдельное письмо, копия видна в Cc. Проверить запись копии в списке отправленных писем.
